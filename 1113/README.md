2. 내 발표 — 응용 8_6_1 블록 쌓기 게임
프로젝트 목표
기존의 간단한 콘솔 블록 쌓기 게임의 기본 구조는 유지하면서,
화면 출력 문제와 조작 오류를 수정하고, 게임 목표·난이도·UI·효과와 연출을 추가하여 하나의 완성된 게임 형태로 업그레이드했다.

원본 게임은 좌우로 이동하는 블록을 원하는 위치에서 떨어뜨리고, 총 15번 동안 최대한 높게 쌓는 방식이었다.
원본 코드 구조
주요 함수는 다음과 같다.
- left_right_move() : 블록 좌우 이동 및 키 입력 처리
- move_down() : 선택한 위치에서 블록 낙하
- max_block() : 현재 가장 높은 블록 높이 계산
- block_stack[] : 각 위치에 쌓인 블록 높이 저장
원본 구조를 최대한 유지하면서 문제를 단계적으로 수정했다.
3. 총 14가지 업그레이드
1차 수정 — 화면 출력 개선
1. UTF-8 콘솔 출력 적용
   - SetConsoleOutputCP(CP_UTF8) 추가
   - 한글 및 유니코드 문자 출력 안정화
2. 블록 모양 개선
   - 기존 □ 블록을 ██ 형태로 변경
   - 블록의 가시성 향상
3. 게임 테두리 출력 방식 변경
   - 기존 문자 코드 조합 방식 제거
   - UTF-8 유니코드 테두리를 직접 출력하도록 수정
2차 수정 — 조작 및 오류 개선
4. 오른쪽 테두리 충돌 오류 수정
   - 블록이 오른쪽 테두리를 덮어쓰는 문제 해결
5. Space 키 전용 낙하
   - 기존에는 아무 키나 눌러도 블록이 떨어졌지만
   - Space 키를 눌렀을 때만 낙하하도록 변경
6. 입력 버퍼 처리 개선
   - 블록이 떨어지는 동안 입력한 키가 남아 다음 블록이 자동으로 떨어지는 문제 해결
   - 착지 후 불필요했던 추가 getch() 제거
7. 마지막 블록 높이 표시 오류 수정
   - 15번째 블록 착지 후 max_block()을 다시 계산하여 최종 높이가 정상적으로 표시되도록 수정
3차 수정 — 게임 시스템 확장
8. 콘솔 화면 자동 배치
   - 현재 PowerShell 창 크기를 계산
   - 게임판과 UI를 중앙에 자동 배치
   - 화면 크기에 따라 블록의 가로 크기도 조절
9. 조작 UI 및 재시작/종료 기능
   - 왼쪽에 조작법 표시
   - R : 다시 시작
   - ESC : 종료
10. 난이도 선택
    - 쉬움 / 보통 / 어려움 추가
    - 난이도에 따라 Sleep() 대기시간을 변경
    - 대기시간이 짧을수록 블록이 더 빠르게 움직임
11. 목표 높이 및 성공/실패 조건
    - 목표 높이 10 추가
    - 10에 도달하면 GAME CLEAR
    - 15번의 기회를 모두 사용하면 GAME OVER
효과 및 연출 개선
12. 높이 상승 +1 피드백
    - 단순히 블록을 놓는 것이 아니라
    - 실제 최고 높이가 증가했을 때만 +1 표시
13. 상황별 효과음
    - 수업에서 사용했던 Beep() 활용
    - 블록 착지
    - 높이 상승
    - 게임 성공
    - 게임 실패
   상황마다 서로 다른 효과음 적용
14. 게임 종료 애니메이션
    - 게임판을 위에서부터 한 줄씩 삭제
    - 이후 GAME CLEAR 또는 GAME OVER 결과 화면 출력
    - 테트리스의 종료 연출에서 아이디어를 얻어 구현
4. 최종 결과
최종적으로 원본의 단순한 블록 쌓기 프로그램을
목표와 난이도, 조작 UI, 피드백, 효과음과 종료 연출이 존재하는 콘솔 게임

으로 확장했다.

단순히 기능을 많이 추가하는 것보다 먼저 원본의 문제점을 수정하고,

화면 출력 → 조작 및 오류 → 게임 시스템 → 효과 및 연출

순서로 단계적으로 업그레이드했다.
