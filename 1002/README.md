2. 음계와 주파수
컴퓨터에서 저장된 음원 파일을 재생하는 대신
주파수를 이용하여 기계적인 음을 출력할 수 있다.
수업에서는 피아노의 기준음인 라(A) = 440Hz를 기준으로 설명했다.
한 옥타브는 주파수가 2배가 되며,
12평균율에서는 한 옥타브를 12개의 반음으로 나누어 사용한다.
이번 실습에서는 가장 낮은 도(C)의 기준값을 다음과 같이 사용한다.
double do_scale = 32.7032;
한 반음씩 올라갈 때 사용할 비율은 다음과 같이 계산한다.
double ratio = pow(2.0, 1.0 / 12.0);
pow()를 사용하므로 다음 헤더가 필요하다.
#include <math.h>
3. Beep() 함수
Windows에서는 다음 함수를 이용해 지정한 주파수의 소리를 출력할 수 있다.
Beep(frequency, duration);
예:
Beep(440, 500);
- 440 : 주파수(Hz)
- 500 : 지속 시간(ms)
Beep()를 사용하려면 다음 헤더가 필요하다.
#include <windows.h>
4. 숫자키 피아노
숫자키와 음계를 다음과 같이 연결한다.
숫자키	음
1	도
2	레
3	미
4	파
5	솔
6	라
7	시
8	높은 도


scanf()를 사용하면 숫자를 입력한 뒤 Enter를 눌러야 하므로
음을 연속적으로 연주하기 어렵다.
따라서 이번 실습에서는 Enter가 필요 없는 getch()를 사용한다.
code = getch();
문자 '1'의 코드값은 49이므로 배열의 첫 번째 인덱스인 0으로 변환하기 위해:
code = code - 49;
를 사용한다.
'1' = 49 → 49 - 49 = 0
'2' = 50 → 50 - 49 = 1
...
'8' = 56 → 56 - 49 = 7
ESC 키의 코드값 27을 이용해 프로그램을 종료한다.
5. 자료구조 복습
자료구조 분류
자료구조
├─ 선형 구조
│  ├─ 배열

배열
수업에서 배열은 다음과 같이 정리했다.
크기가 정해진 동일한 데이터 타입의 연속적인 기억 공간

배열은 인덱스를 이용해 빠르게 접근할 수 있지만
기본적으로 사용할 크기를 미리 정해야 한다.
연결 리스트
연결 리스트의 각 노드는:
Data Field + Link Field
형태로 구성된다.
게임에서는 플레이 도중 발생한 키 입력을 노드에 순서대로 저장한 뒤
나중에 다시 읽어 Replay 기능을 구현하는 예로 설명했다.
동적 메모리 할당
프로그램 실행 중 필요한 만큼 메모리를 확보한다.
malloc()
사용이 끝난 메모리는 반환한다.
free()
스택
스택은 LIFO(Last In First Out) 구조이다.
Push → 데이터 추가
Pop  → 데이터 삭제
Top  → 현재 가장 위의 데이터
게임의 카드 더미처럼 가장 위에서 데이터를 추가하고 제거하는 구조에 사용할 수 있다.
