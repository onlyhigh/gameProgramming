# 게임프로그래밍

## 이번 주 학습 내용

- 숫자와 문자열 출력
- 높은 자리 / 낮은 자리부터 숫자 출력
- 문자열의 Null 문자
- `strlen()`을 이용한 문자열 길이
- `/`, `%`, `pow()`를 이용한 자리수 처리
- 재귀 함수(Recursive Function)
- 꼬리 재귀(Tail Recursion)
- 디지털 숫자 출력
- ASCII Code / Scan Code
- 방향키를 이용한 콘솔 객체 이동
- ESC 키(ASCII 27)를 이용한 종료

## 실행 환경

- VS Code
- GCC
- MSYS2
- Windows Console
