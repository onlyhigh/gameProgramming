# 블록 쌓기 게임 업그레이드

## 파일
- `응용8_6_1.cpp` : 교수님 제공 원본
- `응용8_6_1_수정본.cpp` : 업그레이드 진행본

## 현재까지 수정한 내용
1. 블록 표시 `□` → `██`
2. 게임 테두리 UTF-8 문자로 변경
3. UTF-8 콘솔 출력 적용
4. 오른쪽 경계 오류 수정
5. 스페이스바 입력 시에만 블록 낙하
6. 낙하 중 누적된 키 입력 제거
7. 착지 후 다음 블록 자동 시작
8. 마지막 블록의 높이 결과 반영

## 진행 예정
- 천장 충돌 및 종료 조건
- 블록 이동 속도 변화
- 점수 시스템
- 착지 효과
- 게임 종료 및 재시작
