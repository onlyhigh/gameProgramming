확장키를 getch()로 입력하면 첫 번째 호출에서 0 또는 224(0xE0)가 반환될 수 있다. 이 경우 getch()를 한 번 더 호출하면 실제 Scan Code를 얻을 수 있다.

주의

강의자료의 0xA6, 0xA3 등의 확장 완성형 출력은 예전 한글 코드 페이지를 전제로 한 방식이다. UTF-8 터미널에서는 모서리/선 문자가 자료와 똑같이 보이지 않을 수 있다.

또한 강의자료에는 OCR 과정에서 ₩n으로 보이는 부분이 있는데, C 코드에서는 줄바꿈 문자 \n으로 작성했다.
